Spark Documentation

Spark is a custom-built, interpreted programming language featuring dynamic typing and built-in memory management keywords.

Keywords

The following reserved keywords are used in Spark:

null, true, false, var, free, func, return, if, while, INT, FLOAT, BOOL, STRING.

Data Types

  • NULL: Represented by the null keyword.
  • BOOL: Boolean values true and false.
  • NUMBER: Supports both Integers and Floats.
  • STRING: Text enclosed in single or double quotes.
  • ARRAY: Sequential data containers.

Variable Management

Variables are declared using var and can be manually cleared from memory using free.

var x = 10; // Declaration x = 20; // Assignment free x; // Manual memory release

Function Management

Functions are declared using func and can be manually cleared from memory using free.

func greet(variation) { // Declaration if variation == 0 { print("Hello!"); } if variation == 1 { print("Hi!"); } if variation == 2 { print("Welcome!"); } } greet(0); // Call greet(1); // Call greet(2); // Call

Built-in Functions

Spark comes with several built-in utilities:

  • print(...): Outputs values to the console.
  • printf(format, ...): Formatted output using %s, %d, or %f templates.
  • input(...): Prompts the user for input.
  • cSet(container, idx, value): Sets a value in a container at the index.
  • cGet(container, idx): Gets a value from a container at the index.
  • cAdd(container, value): Appends a value to a container.
  • cLength(container): Returns the length of an array or string.
  • cContains(container, value): Returns if a value is in a container.
  • strStrip(string): Strips the string of whitespace on the right and left.
  • hash(value): Returns the hash of a value.
  • repr(value): Returns the code representation of a value.
  • exit(): Halts program execution.
